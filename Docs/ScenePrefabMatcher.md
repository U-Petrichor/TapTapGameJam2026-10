# 场景预制体匹配工具

打开 Unity 菜单 **Tools → Prefab Matcher → 场景物体批量替换**。

1. 把做好 Collider 的预制体放进 `Assets/Prefabs/Environment/Wall`。也可以在 Project 面板右键一个预制体，选择 **查找场景中的同类物体**。
2. 工具默认扫描当前场景的 `Scene/Environment`。修改“扫描根物体”可指定其他范围；留空扫描当前场景。
3. 保持窗口打开，新增或修改预制体、调整场景后会自动更新结果。自动检测不会改动场景。
4. 展开匹配分组检查名单，可以点击物体名称在 Hierarchy/Inspector 中查看。取消不需要的勾选，点击 **替换勾选的 N 个物体**。
5. 检查 Collider 后按 **Ctrl+S** 保存。默认备份替换前的实时场景，并支持 **Ctrl+Z** 一次撤销这一批替换。也可以勾选“完成后保存场景”。

默认开启 **替换后为全部已连接的匹配物体编号、排序**。例如 `Wall1_1、Wall1_2、…、Wall1_10`；每个预制体在扫描范围内独立从 1 连续编号，不同父级共用这一计数。数字按数值排序，所以 `_10` 会排在 `_9` 后面。同一父级中的匹配实例集中放到该父级末尾；其他物体之间的相对顺序保持不变，物体的父级不变。

以前替换过的实例也可以点击 **只编号并排序已连接的 N 个物体** 单独整理。已编号的实例优先保持编号顺序，新实例排在后面；重复整理不会改变已经正确的名称和顺序。尚未替换的普通物体不会被提前改成预制体名称。若新名称与未匹配的同级物体冲突，工具会提示而不修改场景。编号、排序和本次替换支持一次 Ctrl+Z 一起撤销。

“指定一个预制体”留空时，使用目录下的所有样本。只想处理一种物体时，直接把样本拖进这个字段。

匹配允许 FBX 的微小浮点误差，并比较顶点和三角面连接关系。名称、材质、场景位置、旋转、缩放不同不会阻止匹配。每个候选 Mesh 只读取一次，同一个 Mesh 的物体共用匹配结果。重复样本优先沿用范围内使用最多的预制体。

高级设置默认开启 **识别烘焙在网格内部的旋转，并补偿子 Collider**。有些 FBX 会把模型朝向直接写进顶点，即使场景 Transform 一致，它们的局部网格方向也不同。工具先尝试原方向匹配，再用几何主轴生成旋转候选，只有对齐后所有顶点及每个子网格的三角面连接、绕序都一致才接受。顶点或索引排列不同也可识别；不会通过拉伸或镜像网格来强行匹配。几何主轴存在重复特征值的对称网格可能无法得到稳定旋转，此时仍可能漏匹配。

几何容差建议保留默认 `0.0001`。Chair2 的烘焙旋转导致原来只能匹配 1 个；开启旋转匹配后，GameScene 的 Scene/Environment 下匹配 9 个，其中 8 个待替换，1 个已连接。对齐误差约 `0.0000037`，无需增大到 `0.01`。

替换保留原物体与 Transform、MeshFilter、MeshRenderer 的引用，以及原网格、材质、渲染设置、位置、旋转、缩放和父级。关闭编号排序时，名称和顺序也保持原样。Collider 从预制体继承；网格和材质的差异保留为实例覆盖。以后修改预制体中的 Collider，即可同步到没有 Collider 独立覆盖的实例。

已有 Collider 的普通物体默认列为“需检查”。勾选“使用预制体碰撞体，替换现有 Collider 设置”后可以处理它们，也可还原匹配实例的 Collider 覆盖。

椅子等物体常把碰撞体放在名为 `Collider` 的子物体上，这种结构现在可以处理。工具根据组件识别，不依赖子物体名称。勾选使用预制体碰撞体后，清理多余的旧 Collider，并继承预制体定义的根节点或子节点 Collider。旧辅助节点保留；属于模板的碰撞体节点采用模板中的局部位置、旋转、缩放和设置，不属于模板的旧节点保持原状。子物体有网格、脚本、其他行为组件或独立预制体时，仍会列为“需检查”。

根物体带脚本或其他行为组件、嵌套实例，以及目录外的预制体连接会保留并列出原因。

模型与 BoxCollider 方向相差 45° 时，可以使用以下预制体结构：

```text
Chair2（MeshFilter + MeshRenderer，保留模型）
└─ Collider（BoxCollider，独立调整 Transform 旋转、位置、缩放）
```

工具支持这样的碰撞体子层级，并继承其 Collider。批量替换时，模型的原网格、位置、旋转和缩放保持不变。网格方向一致时，子 Collider 使用预制体中设置的角度；网格内部有烘焙旋转时，工具将同样的旋转及中心偏移补偿到第一层碰撞体子节点，其他层级随父节点一起对齐。预制体根节点上的 Collider 无法独立旋转，因此这类匹配会提示先将 Collider 移到子节点。

补偿记录为子 Transform 的实例覆盖，BoxCollider 的 Size、Center 等组件参数仍继承预制体，后续修改会同步。若修改了预制体碰撞体子节点的 Transform，需要重新扫描并点击替换，重新计算补偿。旧子节点与模板节点同名时，节点引用会保留；不属于模板的旧辅助节点仍保留。不要把 MeshFilter/MeshRenderer 移到子物体中，当前匹配仍以根节点模型为样本。

当前版本适用于根节点上的单网格普通预制体及其纯碰撞体子层级。带子网格或行为组件的层级、Prefab Variant 和 FBX 模型资产不会作为样本。尚未提供样本的其他造型不会自动归为墙体。窗口关闭时不会继续扫描。

备份目录：`RecoverySnapshots/PrefabMatcher/`。重新连接已使用同类样本的实例时，工具会显式保留原缩放，避免新预制体的默认 Transform 改变物体尺寸。替换前重新检查匹配，替换后核对外观、Transform、Collider 继承及未选择的组件；不通过会撤回这一批操作。
