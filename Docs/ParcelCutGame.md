# 拆快递小游戏

每轮从六条胶带中随机选择三条，只显示选中的胶带。每条胶带具有 32 个判定点，默认覆盖率门槛为 60%，即覆盖至少 20 个不同点后隐藏；三条全部完成后通知任务实例成功。

## 图片与判定

`ParcelTapeGeometry` 沿 PNG 的长方向扫描 alpha >= 128 的区域，取两侧边缘的中点作为中心线，同时生成轮廓。针对当前六张长条、无分叉素材，中心线最多保存 64 个点；回合从中心线取 32 个检查点。显示与判定读取同一批检查点。

路径和轮廓在编辑器内从原始图片生成，并序列化到场景；发布版本不需要读取 PNG 或开启 TextureImporter 的 Read/Write。现有胶带的位置、尺寸和旋转不参与校准，不会被重置。

更换图片后，可以运行 `Tools/MiniGames/校准拆快递胶带判定路径`。该菜单只更新判定数据并保存所在场景。完整配置菜单也会生成这些数据。

## 输入与进度

- 按下时根据图片轮廓选择胶带，透明矩形区域不会挡住后面的胶带；交叉处选择绘制在上面的胶带。
- 一次拖动只作用于按下时选中的胶带，松手后可以补切或选择其他胶带。
- 连续移动线段覆盖检查点，重复经过不重复计数，单次点击不增加进度。
- 距离计算使用胶带的实际 UI 尺寸；默认两侧各 25% 的容差以当前位置的胶带宽度为基准。
- 橙色检查点未覆盖，绿色已覆盖；当前胶带覆盖率和总进度实时更新。检查点半径只影响显示，不影响判定。

## 验证

`dotnet run --project Tools/ParcelCutChecks/ParcelCutChecks.csproj` 覆盖随机选择、非目标胶带、19/20 个点的门槛、补切、重复经过、停止回合、透明轮廓、斜线方向与实际距离。

本次 Unity 验证读取了六张真实 PNG，确认所有检查点位于不透明区域；使用两个不同的三胶带组合驱动屏幕坐标拖动事件，验证完成隐藏及一次成功回调，并渲染检查点对齐截图。
