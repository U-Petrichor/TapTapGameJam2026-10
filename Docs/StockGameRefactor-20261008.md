# 炒股玩法重构（2026-10-08）

本文保留旧版记录。当前连续绘制、12+2 报价管线、目标报价成交和动态纵轴的实现以 [2026-10-09 说明](StockGameRefactor-20261009.md) 为准。

## 当前规则

- 每个游戏日一次。成功打开面板才消耗次数，提前退出也消耗；新白天重置。
- 总长 20 秒：前 18.5 秒交易，最后 1.5 秒静止展示结果，随后自动关闭。
- 开局显示 6 个历史报价，第 6 个为当前成交价。每 0.5 秒刷新，最后一次在第 18.5 秒发生；新增 37 点，共 43 点。
- 只显示买入、卖出两个按钮。可以反复交易，持仓数量只能是 0 或 1。
- 初始价格为打开游戏时本金的 50%～90%。首次买入前，所有报价不超过这份本金；第一次买入之后解除上限。
- 股价为 float，局内资金与净盈亏为 double，显示两位小数。局内交易不修改玩家整数钱包。
- 正常结束、提前关闭、Esc、白天结束，都以当前价清仓。净盈亏仅在结束时四舍五入一次，半金币远离零，作为整数差额加减真实金币；重复关闭不会再次结算。钱包中其他来源的资金变化保留。
- 零本金无法买入；真实钱包结算限制在 0～int.MaxValue。

## 价格生成

StockPriceGenerator 实现 IStockPriceGenerator，与 StockRound、StockGame、StockChart 分离。

StockGame Inspector 中的 Price Settings 参数：

| 参数 | 默认值 |
|---|---|
| Shock Probability | 0.1 |
| Trend Variation | 0.2 |
| Gentle Min / Max Ratio | 0.01 / 0.03 |
| Shock Min / Max Ratio | 0.3 / 0.7 |

普通变化使用上一跳的实际差值乘以 [0.8, 1.2]。下跌量不能超过当前股价的一半，因此 10 → 5 → 2.5 → 1.25，后续继续基于实际差值变化。

剧烈变化先随机选择涨跌方向，再把当前价格的 30%～70% 加上或减去。例如当前价 100，突变后为 [30, 70] 或 [130, 170]，买入前仍应用本金上限。突变后重新选择平缓变化值，下一跳强制平缓，再恢复 90% / 10% 的判断。

平缓初始变化值和突变后的新变化值为当前价的 1%～3%，方向随机；参考价格最少为开局本金的 10%，使接近零时仍可重新起步。触及买入前上限时重新取向下的平缓变化，避免锁在本金。

后续改公式：替换 IStockPriceGenerator 的实现；只调整幅度和概率：修改 Price Settings。

## 图表与旧场景兼容

StockChart 的时间窗口容纳十三个位置：左侧六个已揭示位置、中间一个即将刷新位置、右侧六个未来位置。未来价格保持空白，只有下一报价的时间位置显示虚线标记。

已有点、折线及标签按照本局累计交易时间持续匀速向左移动，每 0.5 秒移动一个点间距。刷新只追加报价，不重新播放移动动画。离开左边界的折线和点由绘图区的 RectMask2D 裁剪；边缘点仍在窗口内时保持其价格标签完整可读。

StockChartView 独立计算时间窗口和纵轴，便于测试不同帧率。绘图层 StockPlotGraphic 与网格和刻度分离，历史点超过纵轴时按真实坐标裁剪，不压到边界画出假的水平走势。

纵轴固定下限 0，开局以当前可交易报价 P 初始化上限 2P。只有新报价严格小于现有上限的 1/8 或严格大于 7/8 时，才一次性将上限切换为新报价的两倍；边界包含在稳定区间内。例如 [0,200] 中 25 和 175 不缩放，报价 20 触发 [0,40]，之后 [5,35] 内不缩放。旧历史报价不参与纵轴范围计算。

刻度采用五个等距标签，报价间不插值或持续缩放。零价上限最小为 0.01，避免零长度坐标轴；大股价的纵轴计算使用 double，避免两倍价格溢出。

结算阶段立即停住图表，显示最终价格、整数结算盈亏及局内原始浮点盈亏。

MiniGameDefaultSetup 在运行时兼容已有四按钮场景：重用 BuyOne / SellAll，改为买入 / 卖出并居中排列，隐藏 BuyAll / Wait，补齐裁剪组件。已有图表的尺寸、场景终端位置保留。
